How to play

  1. Select a difficulty level.
  2. Click Generate New Puzzle.
  3. Enter numbers from 1 to 9.
  4. Each row must contain unique numbers.
  5. Each column must contain unique numbers.
  6. Each 3×3 box must contain unique numbers.
  7. Click Solve Sudoku to see the solution.
